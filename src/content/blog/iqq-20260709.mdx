QQQ는 오랫동안 나스닥100 대표 상장지수펀드(ETF)처럼 여겨졌습니다. 그런데 더 낮은 보수를 앞세운 IQQ가 등장하면서 “이제 갈아타야 하나?”라는 고민이 커졌습니다. 결론부터 말하면, 장기 투자자에게 수수료는 분명 중요하지만 ETF 선택은 총보수만으로 끝나지 않습니다. 이번 글에서는 QQQ와 IQQ를 보수, 유동성, 추적오차 기준으로 비교합니다.

## IQQ는 어떤 ETF이고 왜 주목받을까?

IQQ는 블랙록 iShares가 출시한 나스닥100 추종 ETF입니다. QQQ와 마찬가지로 나스닥에 상장된 대형 비금융 기업 중심 지수를 따라가지만, 낮은 총보수(Expense Ratio)를 앞세운 점이 다릅니다.

| 항목    | IQQ               |
| ----- | ----------------- |
| 운용사   | BlackRock iShares |
| 추종 지수 | Nasdaq 100 Index  |
| 상장 시장 | NASDAQ            |
| 분배 주기 | 분기                |

## QQQ와 IQQ, 수수료 차이는 얼마나 클까?

QQQ와 IQQ의 가장 직접적인 차이는 보수입니다. QQQ 총보수는 0.18%, IQQ 총보수는 0.12%, 한시적 순보수(Net Expense Ratio)는 0.10%로 제시됐습니다. 0.06%포인트 차이는 작아 보여도 10년 이상 보유하면 누적 비용 차이로 이어질 수 있습니다.

| 구분     | QQQ         | IQQ   |
| ------ | ----------- | ----- |
| 총보수    | 0.18%       | 0.12% |
| 순보수    | 0.18% 기준 확인 | 0.10% |
| 핵심 포인트 | 유동성         | 저보수   |

## 수수료가 낮으면 무조건 더 좋은 ETF일까?

수수료가 낮은 ETF가 항상 체감 비용도 낮은 것은 아닙니다. 실제 매매에서는 호가 스프레드(Bid-Ask Spread), 거래량, 괴리율(Premium/Discount), 추적오차(Tracking Error)가 함께 작동합니다. 특히 신규 ETF는 거래량이 쌓이고 시장조성 기능이 안정되는지 확인해야 합니다.

* 보수: 매년 자동으로 반영되는 비용
* 스프레드: 사고팔 때 즉시 발생하는 비용
* 추적오차: 지수와 실제 수익률의 차이



## QQQ가 여전히 강한 이유는 무엇일까?

QQQ는 보수만 보면 새 저보수 ETF보다 불리해 보일 수 있습니다. 하지만 1999년 이후 쌓인 운용 이력, 큰 자산 규모, 높은 거래량, 옵션 시장 활용도는 여전히 강점입니다. 장기 적립식 투자자는 보수에 민감하고, 잦은 매매 투자자는 체결 안정성을 더 크게 볼 수 있습니다.

| 투자자 유형 | 더 볼 기준    |
| ------ | --------- |
| 장기 적립식 | 보수, 추적오차  |
| 단기 매매  | 거래량, 스프레드 |
| 옵션 활용  | 옵션 유동성    |

## QQQ·IQQ·QQQM·QNDX는 어떻게 비교해야 할까?

나스닥100 ETF 선택은 QQQ와 IQQ만의 문제가 아닙니다. QQQM, QNDX처럼 같은 지수에 접근하는 다른 저보수 대안도 함께 비교해야 합니다. 핵심은 “무엇을 추종하는가”와 “내 매매 방식에 맞는가”입니다.

| 체크 항목 | 확인 이유    |
| ----- | -------- |
| 보수    | 장기 비용 누적 |
| 거래량   | 체결 안정성   |
| 추적 지수 | 성과 비교 기준 |
| 분배·세금 | 실수익 차이   |

## 스톡핑에서 나스닥100 ETF를 어떻게 비교할 수 있을까?

스톡핑 앱에서는 ETF 정보와 종목 비교 화면에서 QQQ, IQQ 같은 나스닥100 ETF의 기본 정보와 구성 흐름을 함께 확인할 수 있습니다. 수수료만 보고 판단하기 어려운 구성종목, 비중, 수익률, 변동성 차이를 한 화면에서 비교하는 데 도움이 됩니다.

1. ETF 티커 검색
2. 보수와 구성종목 확인
3. 수익률·변동성 비교
4. 장기 보유 목적과 매매 빈도 점검

## 나스닥100 ETF 선택, 한 줄로 정리하면?

나스닥100 ETF 선택의 핵심은 “싸다고 끝이 아니다”입니다. 장기 투자자는 낮은 보수와 추적오차를, 자주 매매하는 투자자는 유동성과 스프레드를 우선 점검해야 합니다. QQQ, IQQ, QQQM, QNDX를 같은 기준표에 놓고 비교하면 불필요한 갈아타기보다 합리적인 선택에 가까워집니다.
